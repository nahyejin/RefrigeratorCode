# 요리 릴스 원본 넣는 곳

릴스 한 편 = **① 내가 요리하는 영상 → ② 그 요리에 쿡매치를 쓰는 화면 영상 → ③ 8개 기능 풀영상(`ReelOverview`)**

요리 하나마다 폴더 하나를 만들고, 폴더 이름은 `요리명_YYYYMMDD` 로 한다(날짜는 요리한 날).

```
my-video/public/cooking/
  된장찌개_20261015/
    1_cooking/        ← ① 요리하는 영상(여러 개면 찍은 순서대로 01_, 02_ … 붙이기)
      01_재료손질.mp4
      02_끓이기.mp4
    2_app/            ← ② 쿡매치 화면 녹화(이 요리를 찾고·보고·완료하는 화면)
      01_냉장고요리검색.mp4
    memo.txt          ← (있으면) 꼭 넣을 장면, 자막으로 쓸 말, 레시피 이름·출처
```

- **폰에서 보내기**: 폰 OneDrive 앱으로 `쿡매치_요리영상/요리명_YYYYMMDD/` 에 올리면(사진 앱 → 공유 → OneDrive 도 됨, 원본 화질) PC 의 `C:\Users\user\OneDrive\쿡매치_요리영상\` 로 내려온다(이 폴더는 「항상 이 기기에 유지」). 편집할 때 Claude 가 거기서 이 폴더로 복사해 온다 — `1_cooking`·`2_app` 으로 안 나눠 올려도 되고, 그때 파일 이름·순서를 보고 나눈다.
- 파일 이름은 자유. 앞 번호(01_, 02_)만 있으면 그 순서로 이어 붙인다.
- 폰에서 찍은 그대로(mp4·mov) 넣으면 된다. 세로 9:16 이 기본.
- ③ 8개 기능 풀영상은 이미 있는 `ReelOverview` 를 그대로 붙이므로 따로 넣을 필요 없다.
- **이 폴더의 영상은 git 에 올리지 않는다**(용량이 크고, 화면 녹화에 개인 알림이 찍힐 수 있음). `memo.txt` 와 이 README 만 올라간다. 편집 결과물은 `my-video/out/` 에 나온다.
- 화면 녹화 전에 방해 금지 모드를 켜 두면 알림이 안 찍힌다. 찍혔으면 그 부분은 편집에서 가린다.
