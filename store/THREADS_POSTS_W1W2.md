# 스레드 첫 2주 글 초안

> 기준: `store/THREADS_GUIDE.md`. 사용자 실제 이야기(재료 사이클 → 배달 → 아이 → 다시 요리 → 쿡매치, 남편)만 썼다.
> **[대괄호]** = 사용자만 아는 사실. 실제 값으로 바꾸거나, 모르면 그 줄을 지운다. 꾸며 넣지 않는다.

### 8일 · 정보
- 사진: 대체 재료 표 이미지 (직접 만든 것 / 표를 손글씨로 찍어도 됨)

```
레시피에 있는데 우리 집에 없을 때 대신 쓰는 것

· 대파 없으면 → 양파, 쪽파
· 버터 없으면 → 식용유 + 소금 한 꼬집
· 굴소스 없으면 → 간장 + 설탕 조금
· 생크림 없으면 → 우유 + 버터
· 청주·맛술 없으면 → 소주, 아니면 설탕 아주 조금
· 다진 마늘 없으면 → 마늘가루, 생략해도 대부분 괜찮아

이거 알면 "재료 하나 없어서" 장 보러 나가는 일 확 줄어

다들 대신 쓰는 거 하나씩 알려 줘, 표에 추가할게
```
첫 답글: `저장해 두고 쓰면 편해. 나는 냉장고 문에 붙여 놨어`
> 대체 재료는 쿡매치 대체 재료 표(`substitutes`)에서 실제로 확인한 것만 남기기.
