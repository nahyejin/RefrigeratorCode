# 비회원 로그인 유도 정책 (2026-10-22 확정)

시안: Design 캔버스 「쿡매치 가입 유도 시안」 ①~⑧, 정책서 HTML 「쿡매치 로그인 유도 정책」. 구현은 `frontend/src/utils/loginGate.ts`, `components/LoginGateHost.tsx`, `components/DefaultIngredientsDialog.tsx`, `backend/usage_quota.py`. 변경 이력은 CHANGELOG.md 2026-10-22.

## 한도 (비회원)
- **직접 담은 재료 · 즐겨찾기 · 기록 · 완료 각각 3개까지** 자유, **4번째부터 로그인 필요**. 취소하면 4번째는 저장되지 않는다.
- 기준은 「지금 저장돼 있는 개수」(지우면 다시 담을 수 있음). 재료는 기본 재료(처음 넣어 주는 약 30개)를 세지 않는다.
- 공유: 링크 복사만. 「가족에게 보내기」는 가족 그룹이 있어야 보이므로 비회원에겐 안 보인다. 로그인 유도 없음.

## 팝업 문구
공통: 우측 위 X, 제목 1줄, 본문 한 줄씩, 굵은 경고줄 「로그인하지 않으면 사라질 수 있어요.」
- 재료 4번째: 「재료는 3개까지만 가능해요 / 더 담으려면 로그인해 주세요. / 가입하면 지금 담은 재료가 그대로 이어져요.」[나중에][로그인하기]
- 즐겨찾기·기록·완료 4번째: 「즐겨찾기(기록, 완료)는 3개까지만 가능해요 / 더 저장하려면(남기려면) 로그인해 주세요. / 가입하면 …가 그대로 이어져요.」[취소][로그인하기]
- 두 번째 방문: 「다시 와 주셨네요 / 로그인하면 담아 둔 재료가 안전하게 저장돼요. / 가입하면 지금 재료가 그대로 이어져요.」[나중에][로그인하기]
- AI 체험 소진(경고줄 없음): 「AI 체험을 다 쓰셨어요 / 가입하면 30크레딧을 바로 드려요.」[취소][로그인하기]
- 처음 들어왔을 때: 「자주 쓰는 재료를 담아 뒀어요」 — 기본 재료 칩(연회색, 뺀 것은 점선·취소선), [이대로 시작][로그인하고 시작], 박스 「3개까지만 더 담을 수 있어요. 로그인하지 않으면 사라질 수 있어요.」
- 로그인 화면: 「처음이라면 — 지금 담은 재료가 그대로 저장돼요 / 쓰던 계정이 있다면 — 그 계정의 냉장고가 보여요」(연한 테두리·회색 톤, 비회원 냉장고가 있을 때만)

## 두 번째 방문 팝업 조건
비회원 + 이 기기 2번째 이후 방문 + 이번 방문에 아직 안 띄움 + 마지막으로 띄운 지 7일 + **한 화면 둘러본 뒤 다른 화면으로 처음 이동하는 순간**(켜자마자 아님). 웹에서 「홈 화면에 추가」 안내가 뜰 차례면 양보. 분기는 이 한 가지뿐(담아 둔 재료 유무로 나누지 않음).

## 가입·로그인할 때 데이터
- 새로 가입(계정 냉장고가 비어 있음): 비회원 때 재료·즐겨찾기·완료·기록이 그대로 이전(2026-10-17 구현).
- 이미 가입한 계정으로 로그인: **계정 데이터 우선, 합치지 않음**(기기에서 담은 것은 사라짐) — 사용자 확정.
- 로그인 안 하면 기기(localStorage)에만 있어 앱 삭제·기기 변경 때 사라질 수 있다.

## 크레딧 (`backend/usage_quota.py`, 환경변수로 변경 가능)
- 차감: 챗봇 1 · 사진 인식 2(여러 장도 한 번) · 식단 3.
- 비회원 체험: **6**(기기당 1번, 재충전 없음, 하루 상한 6 = 체험분과 같게). 사진 2 + 식단 3 + 챗봇 1 = 세 기능 한 번씩.
- 가입: 30(1번). 가입 회원 무료: 매주 월요일 6, 하루 상한 15. 유료(plus): 매주 60(대신 들어감), 하루 상한 50, 결제 없이 관리자가 올려 줌.
- 앱을 지우면 새 기기 식별자로 체험분을 다시 받는다 — 알고 있고 막지 않기로 함.
- 소진 문구는 「N개」「5회」 대신 「크레딧」 단위로 통일.

## 측정 (`user_events`)
- `cta_view` / `cta_click` / `cta_dismiss`, detail = `ingredient_limit` · `favorite_limit` · `write_limit` · `done_limit` · `ai_out` · `return_visit`.
- `fridge_edit`: 비회원 `manual` / `photo` / `seed_trim`.
- 기존 `signup` / `login`(10/20)과 합쳐, 어드민 「가입 유도 팝업」 카드에서 팝업별 본 사람·뜬 횟수·누름·닫음, **가입 직전에 마지막으로 누른 팝업**(같은 기기에서 가입 이전의 마지막 cta_click, 없으면 「팝업 없이」)을 본다.
- 이 이벤트는 앱이 보내므로 새 앱 버전(웹은 즉시)부터 쌓인다.

## 첫 시작 흐름 변경 (2026-10-29, 다음 앱 빌드부터)
- 첫 시작 팝업(`DefaultIngredientsDialog`)에서 「3개까지만 더 담을 수 있어요 / 로그인하지 않으면 사라질 수 있어요」 경고와 [로그인하고 시작]을 뺐다. 버튼은 비회원 **[이 재료로 요리 보기]** 하나(회원은 [이대로 시작]). 비회원이 누르면 빼기로 한 재료를 이 기기에 저장하고 `냉장고요리`(/recipe-list)로 이동한다. 한도(직접 담은 재료 3개 등)는 그대로이고 **그 자리에 닿았을 때** 기존 확인창이 뜬다.
- 새 확인창 `save`(detail `save_prompt`, 「이 냉장고, 저장해 둘까요?」[나중에 할게요][3초 만에 저장하기]): 비회원이 **이 기기에서 처음 레시피를 열고 3.5초 뒤** 한 번만 띄운다(`scheduleSavePrompt`, 기기당 1회). 경고 줄 없음.
