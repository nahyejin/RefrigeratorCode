# Google Play 프로덕션 액세스 신청서 — 초안 (2026-10-06 경 제출)

Play Console → 대시보드 → **프로덕션 액세스 신청**. 조건 3개 중 ①비공개 테스트 게시 ②12명 이상 참여는
2026-09-22 에 충족됐고, ③**12명 이상으로 14일 이상 실행**이 차면 「프로덕션 신청」 버튼이 켜진다(≈10/06).

⚠ **제출 전에 반드시 고칠 것**: 아래 〔 〕 안은 그때 실제 값으로 바꾼다. 구글은 답변이 구체적일수록
승인 확률이 높다고 안내하며, 지어낸 내용을 쓰지 않는다(테스터 수·기간은 Console 수치와 맞춘다).

## 1. 비공개 테스트를 어떻게 진행했나

```
비공개 테스트는 2026년 9월 22일에 시작해 〔종료일〕까지 〔14〕일 동안 진행했고, 테스터는 총 〔28〕명입니다.
테스터는 두 갈래로 모았습니다. 하나는 개발자 본인의 가족·지인 중 안드로이드 사용자이고, 다른 하나는
비공개 테스트 테스터 모집을 대행하는 외부 서비스를 통해 모은 테스터입니다.

개인 개발자라 주변에서 안드로이드 사용자 12명을 모으는 일이 가장 어려웠습니다. 가족과 지인은 대부분
아이폰을 쓰고 있어서, 실제로 앱을 설치하고 2주 동안 유지해 줄 수 있는 사람을 채우기 위해 외부 모집
서비스를 함께 이용했습니다.
```

## 2. 테스터가 앱을 어떻게 썼고, 예상과 맞았나

```
테스터들은 냉장고에 재료를 등록하고, 그 재료로 만들 수 있는 레시피 목록을 보고, 레시피 상세(조리 순서)를
여는 흐름을 가장 많이 사용했습니다. 이는 저희가 기대한 핵심 흐름과 일치했습니다.

예상과 달랐던 점은 두 가지입니다.
첫째, 재료를 손으로 하나씩 입력하는 것을 번거로워해서 사진(영수증·음식 사진) 인식 기능의 사용 비중이
생각보다 높았습니다.
둘째, 알림을 켜는 비율이 예상보다 낮았는데, 확인해 보니 기기 설정에 따라 알림이 정상적으로 등록되지
않는 문제가 있었습니다(아래 3번 참고).
```

## 3. 어떤 피드백을 받고 무엇을 고쳤나 (가장 중요한 항목)

아래 표는 [RELEASE_NOTES.md](../RELEASE_NOTES.md) 「Google Play 비공개 테스트 기간 기록」에서 가져온다.
테스트 기간에 새 의견이 들어오면 그 파일에 먼저 적고, 제출 직전에 이 목록을 갱신한다.

```
테스트 기간 동안 받은 의견과 조치는 다음과 같습니다.

1) 어르신(가족) 테스터: 앱을 켤 때 아이콘 화면이 먼저 뜬 뒤 시작 화면이 나와 어색하고, 휴대폰 글꼴을
   크게 설정해 두어 글자가 화면 밖으로 넘쳤습니다.
   → 시작 아이콘 화면을 없애고, 시스템 글꼴 배율을 1.3배까지만 반영하도록 제한했습니다. (버전 1.0)

2) 유통기한 알림이 일부 기기에서 오지 않는다는 점을 테스트 중 확인했습니다. 알림 권한이 이미 허용된
   기기(안드로이드 12 이하 등)에서 알림 등록이 건너뛰어지는 문제였습니다.
   → 권한이 허용된 기기는 묻지 않고 바로 알림을 등록하도록 수정했습니다. (버전 1.0.1, versionCode 2)

3) 요리 챗봇 입력창이 화면 폭을 넘어가는 문제를 발견했습니다.
   → 입력창 레이아웃을 수정했습니다. (버전 1.0.1)

4) 레시피 목록에서 스크롤하면 뒤로 가기 버튼과 제목이 화면 위로 사라져, 목록 중간에서 이전 화면으로
   돌아가기 불편하다는 점을 확인했습니다.
   → 뒤로 가기와 제목을 상단에 고정했습니다. (버전 〔1.0.2〕)

〔테스트 기간에 실제로 받은 의견이 더 있으면 여기에 날짜와 함께 추가〕

테스트 기간 중 앱 업데이트를 〔2〕회 배포해 위 수정 사항을 테스터에게 전달했습니다.
```

## 4. 앱 정보 (목표 사용자·가치 제안)

```
목표 사용자: 장을 봐 두고 다 쓰지 못해 버리는 1~2인 가구, 매일 저녁 무엇을 만들지 고민하는 주부와
자취생, 식비를 줄이고 싶은 가족입니다.

가치 제안: 쿡매치는 냉장고에 있는 재료를 등록하면 그 재료로 만들 수 있는 요리를 매칭률 순으로
보여줍니다. 레시피는 AI가 지어낸 것이 아니라 유튜브·네이버에 공개된 실제 레시피이며 원문 출처로
연결됩니다. 유통기한이 임박한 재료를 먼저 알려 주고, 그 재료부터 쓰는 일주일 식단을 짜 주어
식재료 낭비와 식비를 줄이는 것이 목표입니다. 사진(영수증·음식 사진)으로 재료를 등록할 수 있고,
가족을 초대해 하나의 냉장고를 함께 쓸 수 있습니다.

첫해 예상 설치 수: 〔1,000~5,000〕건 (개인 개발자의 인스타그램 콘텐츠 중심 홍보 기준)
```

## 5. 프로덕션 준비 상태

```
비공개 테스트에서 확인된 문제를 모두 수정해 배포했고, 현재 알려진 미해결 문제는 없습니다.
동일한 앱이 iOS App Store 에 2026년 9월 심사를 통과해 출시되어 운영 중이며, 서버·데이터베이스·
푸시 알림(FCM/APNs) 모두 실제 사용자 대상으로 동작하고 있습니다.

개인정보처리방침, 계정 및 데이터 삭제 안내 페이지(앱 내 탈퇴 및 웹 요청 경로), 데이터 보안 신고를
모두 준비했고, 탈퇴 시 이용자의 콘텐츠를 즉시 삭제하도록 구현했습니다.
출시 후에도 인스타그램 채널을 통해 사용자 의견을 받고 정기적으로 업데이트할 계획입니다.
```
