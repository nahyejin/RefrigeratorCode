# Google Play Console 설문 답안지 (2026-09-19 작성)

앱을 만든 뒤 나오는 설문에 그대로 옮겨 적기 위한 답안이다. **실제 코드·개인정보처리방침을 보고 썼고**, 근거를 각 줄에 적었다. Play Console 의 문항 문구는 바뀔 수 있으니, 화면의 문항이 여기와 다르면 **뜻이 가장 가까운 것**을 고르고 모호하면 Claude 에게 화면을 보여줄 것.

먼저 아래 「0. 답하기 전에 정할 것」 을 읽는다 — 방침과 코드가 어긋난 곳이 있어, 그대로 제출하면 심사에서 걸릴 수 있다.

## 1. 앱 액세스 (앱 콘텐츠 → 앱 액세스 권한)

- **답**: "앱의 일부가 제한됨" (로그인해야 쓰는 기능이 있음)
- 근거: 비회원은 재료·레시피는 쓸 수 있지만 AI(챗봇·식단·사진 인식)는 기기당 체험 횟수만 되고(`usage.ts` `guest_trial`), 가족 공유·푸시 알림은 로그인이 필요하다.
- **심사용 테스트 계정을 준비해서 입력**해야 한다: 이메일/비밀번호 로그인 계정 1개를 직접 가입해 만든다(가입에 이메일 인증코드가 필요하니 본인 메일로 미리 만들어 둘 것). 안내 문구 예:
  > 앱 첫 화면 → "로그인/회원가입" → 이메일 로그인. 이메일: (테스트 계정), 비밀번호: (테스트 비밀번호). 구글·카카오·네이버 로그인은 각자의 계정이 필요합니다. 로그인 없이도 재료 입력과 레시피 보기는 가능합니다.

## 2. 광고 (앱 콘텐츠 → 광고)

- **답**: "예, 앱에 광고가 포함되어 있습니다"
- 근거: 쿠팡 파트너스 배너·상품 링크(`CoupangAd.tsx` 등). 앱 안에 "쿠팡 파트너스 활동의 일환으로 수수료를 받을 수 있음" 고지가 있다(`CoupangDisclaimer`).

## 3. 광고 ID 사용 여부

- **답**: **"아니요"** (광고 ID 사용 안 함)
- 근거: 빌드된 앱의 권한 목록에 `AD_ID`(`com.google.android.gms.permission.AD_ID`)가 없다. 있는 권한은 `INTERNET`, `POST_NOTIFICATIONS`, `ACCESS_NETWORK_STATE`, `WAKE_LOCK`, `c2dm.permission.RECEIVE` 뿐. (쿠팡 스크립트는 웹뷰 안이라 안드로이드 광고 ID 에 접근하지 않는다)

## 4. 대상 연령층 (앱 콘텐츠 → 대상 연령층 및 콘텐츠)

- **권장 답**: **18세 이상**만 선택.
- 이유: 아이 대상 앱으로 분류되면 "가족 정책"의 추가 요건(광고·데이터 제한 등)이 붙는다. 요리·장보기 앱이고 어린이를 겨냥하지 않는다.
- "어린이에게 매력적인 앱이냐"는 문항 → **아니요**.

## 5. 콘텐츠 등급 (IARC 설문)

- **카테고리**: "유틸리티, 생산성, 커뮤니케이션 또는 기타"(게임·소셜 미디어·뉴스 아님).
- 폭력 / 성적 콘텐츠·노출 / 욕설 / 약물·알코올·담배 / 도박 / 공포: 모두 **아니요**. (레시피 앱이라 술 재료가 나올 수는 있지만 음주를 권장·묘사하는 콘텐츠가 아님)
- **사용자 간 상호작용 / 사용자 생성 콘텐츠**: [STORE_LISTING.md](STORE_LISTING.md) 결정대로 **예** — 가족 그룹원끼리 냉장고·기록을 공유하고, AI 챗봇과 대화한다. 다만 **공개 게시·낯선 사람과의 채팅은 없다**는 점이 문항에 있으면 그대로 반영.
- 위치 공유 **아니요**, 디지털 상품 구매 **아니요**, 인터넷 접속은 가능.
- 예상 결과: 전체 이용가 / 만 3세 이상 정도.
