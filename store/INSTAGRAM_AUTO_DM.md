# 인스타 자동 DM — 팔로우 + 댓글 「쿡매치」 → 자료 보내기

요리 릴스 3편부터 쓴다(2026-11-01 사용자 결정). 릴스를 본 사람이 **팔로우하고 댓글에 「쿡매치」**를 남기면 소분 체크리스트·레시피 PDF 링크를 DM으로 자동으로 보낸다.

## 왜 도구가 필요한가

- 인스타 자동 DM은 Meta 공식 파트너 도구(ManyChat 등)를 계정에 연결해야 한다. Claude 는 인스타·ManyChat 에 로그인할 수 없어서 **연결과 버튼 설정은 사용자가 직접** 하고, 흐름·문구는 이 문서대로 넣는다.
- 인스타 DM 에는 PDF 파일을 바로 첨부할 수 없다. **PDF 는 링크로** 보낸다(아래 「자료 링크」).

## 준비 (한 번만)

1. 인스타 계정이 **프로페셔널(크리에이터 또는 비즈니스)** 계정인지 확인
2. 인스타 앱 → 설정 → 메시지와 스토리 답장 → 메시지 제어 → 연결된 도구 → **메시지 접근 허용** 켜기
3. ManyChat 가입 → Instagram 채널 연결(페이스북 페이지 연결이 필요할 수 있음)
4. 자료 링크 만들기: OneDrive `쿡매치_요리영상/쿡매치_캠핑_새우알리오올리오_DM.pdf` (3쪽: ① 소분 체크리스트 ② 순서와 이유 ③ 원래 레시피 + 쿡매치 받기 링크) → 공유 → **링크가 있는 모든 사용자 · 보기 전용** → 링크 복사

## 흐름 (ManyChat 자동화 하나로 두 입구를 받는다)

| 단계 | 설정 |
|---|---|
| 입구 ① | 트리거 **Post or Reel Comments** → 이 릴스 선택 → 키워드 `쿡매치` (띄어쓰기·이모지 섞여도 잡히게 「포함」) |
| 입구 ② | 트리거 **Direct Message** 키워드 `쿡매치` — 댓글로 자료가 안 왔을 때 DM으로 받는 길 |
| 댓글 공개 답글 | 「DM 확인해 주세요 💌」 (여러 문구를 돌아가며 쓰기 — 같은 답글 반복은 스팸으로 보일 수 있음) |
| 조건 | **팔로우 여부(Is follower)** |
| 팔로우 O | 자료 메시지 보내기 |
| 팔로우 X | 팔로우 안내 메시지 + **「팔로우했어요」 버튼** → 버튼을 누르면 다시 팔로우 확인 → O 면 자료, X 면 같은 안내 한 번 더 |

**「댓글 먼저, 팔로우 나중」 문제**: 댓글을 단 순간에는 팔로워가 아니라서 자료가 안 간다. 그래서 팔로우 X 쪽에 꼭 「팔로우했어요」 버튼을 둔다. 버튼을 누르는 순간 다시 확인하니까, 나중에 팔로우한 사람도 받는다. 그래도 안 오면 입구 ②(DM 키워드)로 받게 본문·안내에 적어 둔다.

## 메시지 문구

**팔로우 X (첫 DM)**
```
댓글 고마워요 😊
캠핑용 소분 체크리스트와 상세 레시피는 팔로워분들께 보내 드리고 있어요.
팔로우하신 뒤 아래 「팔로우했어요」를 눌러 주세요!
```
버튼: `팔로우했어요`

**자료 보내기 (팔로우 O)**
```
캠핑 새우 알리오올리오 소분 체크리스트와 상세 레시피예요 🍝
👉 [자료 링크]

캠핑 버너는 불이 가운데만 세서, 면이랑 새우를 따로 먼저 익히는 게 포인트예요.
쿡매치 앱에서 「알리오올리오」를 검색하면 원래 레시피와 내 재료에 맞는 대체 재료도 볼 수 있어요.
```
버튼: `자료 열기` (링크)

## 지켜야 할 것

- 댓글 자동 DM은 **댓글이 달린 뒤 7일 안**에만 보낼 수 있다(인스타 정책). 오래된 댓글은 직접 보낸다.
- 자동 답장이 막히거나 늦을 때를 대비해 본문 끝에 「DM이 안 오면 DM으로 「쿡매치」라고 보내 주세요」를 꼭 넣는다.
- 편마다 PDF·링크가 바뀌면 ManyChat 의 「자료 보내기」 링크와 키워드 대상 릴스만 바꾼다.
