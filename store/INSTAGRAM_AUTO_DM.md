# 인스타 자동 DM — 팔로우 + 댓글 「쿡매치」 → 자료 보내기

요리 릴스 3편부터 쓴다(2026-11-01 사용자 결정). 릴스를 본 사람이 **팔로우하고 댓글에 「쿡매치」**를 남기면 소분 체크리스트·레시피 PDF 링크를 DM으로 보낸다.

**지금은 ManyChat 무료 플랜으로 시작한다**(사용자 2026-11-01). 유료(월 $17~)는 댓글이 많아지면 그때 검토.

## 무료 플랜이라 생기는 한계와 대응

| 한계 | 대응 |
|---|---|
| 무료는 **활성 연락처 수가 적다**(2026년 3월 축소, 25명 안팎이라는 자료가 많음 — 가입 후 실제 한도 확인) | 한도가 차면 자동 DM 이 멈춘다 → 받은 「쿡매치」 댓글·DM 을 보고 **아래 「직접 보낼 때」 문구로 손으로** 보낸다 |
| **팔로우 확인 조건**(Is follower)이 무료에서 되는지 확실하지 않음 | 되면 「흐름 A」, 안 되면 「흐름 B」(팔로우 부탁 + 버튼, 확인 없이 보냄) |
| 본문에 「자동 발송」이라고 쓰면 늦을 때 불만 | 본문에는 「보내 드려요」까지만. 「자동」, 「하루 안에 안 오면…」 같은 말은 쓰지 않는다(사용자 2026-11-01). DM 키워드 입구는 ③ 메시지 안에서만 안내 |

## 준비 (한 번만)

1. 인스타 → **크리에이터** 계정으로 전환(무료, 언제든 되돌릴 수 있음. 비즈니스는 음악 라이브러리가 일부 제한돼서 크리에이터)
2. 인스타 앱 → 설정 → 메시지와 스토리 답장 → 메시지 제어 → 연결된 도구 → **메시지 접근 허용** 켜기
3. ManyChat 무료 가입 → Instagram 연결
4. 자료 링크: OneDrive `쿡매치_요리영상/쿡매치_캠핑_새우알리오올리오_DM.pdf` (3쪽: ① 소분 체크리스트 ② 순서와 이유 ③ 원래 레시피 + 쿡매치 받기 링크) → 공유 → **링크가 있는 모든 사용자 · 보기 전용** → 링크 복사 → 아래 `[자료 링크]` 자리에 넣기

## 흐름

입구는 둘이다. ① 릴스 댓글 키워드 `쿡매치`(이 릴스만, 「포함」으로) ② DM 키워드 `쿡매치`(댓글로 못 받은 사람용).

**흐름 A — 팔로우 확인이 될 때**
```
댓글/DM 「쿡매치」 → [댓글 공개 답글] → 팔로우했나?
   ├ 예 → [② 자료]
   └ 아니요 → [① 팔로우 부탁] + 버튼 「팔로우했어요」 → 다시 확인 → 예면 [② 자료] / 아니요면 [③ 아직이에요]
```

**흐름 B — 팔로우 확인이 안 될 때(무료 기본)**
```
댓글/DM 「쿡매치」 → [댓글 공개 답글] → [① 팔로우 부탁] + 버튼 「팔로우했어요」 → 버튼 누르면 [② 자료]
```
확인은 못 하지만 버튼을 한 번 누르게 해서 팔로우를 유도한다. 「댓글 먼저, 팔로우 나중」인 사람도 버튼을 누르면 받는다.

## 메시지 문구

**댓글 공개 답글** (3개를 돌아가며 — 같은 답글 반복은 스팸으로 보일 수 있음)
```
DM 확인해 주세요 💌
보내 드렸어요! DM함을 확인해 주세요 🍝
DM으로 보내 드렸어요 😊 캠핑 맛있게 다녀오세요!
```

**① 팔로우 부탁 (첫 DM)**
```
댓글 고마워요 😊
캠핑용 소분 체크리스트와 상세 레시피는 팔로워분들께 보내 드리고 있어요.
팔로우하신 뒤 아래 「팔로우했어요」를 눌러 주세요!
```
버튼: `팔로우했어요`

**② 자료**
```
캠핑 새우 알리오올리오 소분 체크리스트와 상세 레시피예요 🍝
👉 [자료 링크]

캠핑 버너는 불이 가운데만 세서, 면이랑 새우를 따로 먼저 익히는 게 포인트예요.
쿡매치 앱에서 「알리오올리오」를 검색하면 원래 레시피와 내 재료에 맞는 대체 재료도 볼 수 있어요.
```
버튼: `자료 열기` (링크)

**③ 아직이에요 (흐름 A 에서 버튼을 눌렀는데 팔로우가 안 잡힐 때)**
```
아직 팔로우가 확인되지 않았어요 🥲
팔로우하신 뒤 1~2분 있다가 다시 눌러 주세요.
그래도 안 되면 DM으로 「쿡매치」라고 보내 주세요. 바로 보내 드릴게요!
```
버튼: `팔로우했어요`

**직접 보낼 때** (무료 한도가 찼거나, 7일 지난 댓글, DM 으로 「쿡매치」가 왔는데 자동이 안 돈 경우) — ②를 그대로 복사해서 보낸다.

## 지켜야 할 것

- 댓글에 대한 자동 DM 은 **댓글이 달린 뒤 7일 안**에만 보낼 수 있다(인스타 정책). 그 뒤 댓글은 직접 보낸다.
- 편마다 바뀌는 것: 댓글 키워드 대상 릴스, ② 의 요리 이름·포인트 한 줄, `[자료 링크]`.
- **로고(새 로고 P1 확정 2026-11-07)**: 자동 DM 문구·레시피 카드 이미지(`store/cooking_recipe_dm/ep3_*.png`)에는 로고가 들어 있지 않다 → 변경 없음. 인스타 프로필 사진(`@Cook._.match`, App Store 「마케팅 URL」이 이 페이지)은 사용자가 인스타 앱에서 `store/brand/cookmatch_mark_1024.png` 로 직접 바꾼다(원형으로 잘려도 큰 잎이 안 잘리는지 확인).

## PDF 안 「쿡매치 받기」 링크 꼬리표 (4편부터 규칙)

PDF 를 받은 사람이 앱으로 넘어왔는지 편마다 따로 보려고, PDF 맨 끝 쿡매치 받기 링크에 **편 이름 꼬리표**를 붙인다(사용자 2026-11-01).

```
https://refrigerator-code.vercel.app/download?utm_source=dm_pdf_<편이름>&utm_medium=pdf&utm_campaign=<편이름>
```

| 편 | 편이름 | 꼬리표 |
|---|---|---|
| 3편 캠핑 새우 알리오올리오 | `camping` (캠페인 `camping_alioolio`) | `dm_pdf_camping` — 이미 적용됨 |
| 4편부터 | 영어 소문자·밑줄, 요리를 알아볼 수 있게(예: `leftover_pasta`) | `dm_pdf_<편이름>` |

- 어드민 「어디서 들어왔나」가 `dm_pdf_*` 를 이미 「DM PDF」로 풀이해 준다. 인스타 묶음과 별개로 보인다.
- PDF 자체를 보내는 링크(OneDrive 공유 링크)에는 꼬리표를 붙이지 않는다 — 앱 유입은 PDF 안 링크에서만 센다.
- 편 이름을 정하면 이 표에 한 줄 더한다.
- 하루 댓글이 20~30개를 넘어 손으로 보내기 벅차면 유료(Essential 월 $17~) 검토. 팔로우 확인 기능이 어느 요금제부터인지 manychat.com/pricing 에서 확인.
