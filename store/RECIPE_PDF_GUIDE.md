# 레시피 PDF 만들기 (DM·댓글로 보내는 정리본)

직접 요리 릴스에서 「댓글에 ‘쿡매치’ 남기면 DM 으로 보내 드려요」 할 때 보내는 PDF. 2026-11-01 사용자와 정한 형식.
**본보기:** [scripts/hub_post_files/dm/camping_alioolio.html](../scripts/hub_post_files/dm/camping_alioolio.html) — 새 레시피는 이 파일을 복사해서 내용만 바꾼다.

## 만드는 순서

1. 본보기 HTML 을 `scripts/hub_post_files/dm/<요리이름>.html` 로 복사해 내용을 바꾼다.
2. `python scripts/make_dm_pdf.py scripts/hub_post_files/dm/<요리이름>.html` → 같은 이름 `.pdf`(크롬 헤드리스 인쇄, 링크가 살아 있음).
3. 쪽마다 그림으로 뽑아 **직접 보고** 잘린 데가 없는지 확인한다(아래 「쪽 나눔」).
4. 올리기 아티팩트: `scripts/hub_post_files/cooking_posts.json` 의 해당 편에 `pdf` 필드(`src`·`name`·`info`)를 넣고 `gen_hub.py` → 아티팩트를 `files` 에 PDF 를 붙여 다시 올린다. 카드에 「PDF 저장」 버튼이 생긴다.
5. OneDrive `쿡매치_요리영상` 에도 `쿡매치_<요리>_DM.pdf` 로 복사.

## 구성 (3쪽, 쪽마다 한 덩어리)

| 쪽 | 들어가는 것 |
|---|---|
| ① | 제목 + 칩(몇 인분 · 도구와 크기 · 걸리는 시간) + **소분 체크리스트**(양념 / 재료, 칸마다 체크 상자) + 한 줄 메모 |
| ② | **만드는 순서**(숫자 동그라미) + **초록 상자 「원래 레시피와 다르게 한 이유」** |
| ③ | **원래 레시피**(쿡매치에서 찾은 그 레시피 그대로: 재료 한 줄 + 순서) + **노란 상자 쿡매치 받기** |

- 맨 위에 「N편 · 날짜 · 캠핑」 같은 소제목 줄은 넣지 않는다.
- 도구 크기가 레시피 선택의 이유면 칩과 초록 상자에 같이 쓴다(예: 캠핑·백패킹 프라이팬은 1.5~1.6L가 가장 큰 편이라 그 팬 하나로 되는 순서).

## 양 쓰는 법

- **숫자 단위를 먼저**(g · ml · 큰술 · 작은술 · 개 · 알), 사용자가 말한 어림 표현은 그 아래 **괄호**로 남긴다.
  - 예: `약 1큰술 (엄지손가락만큼)` · `약 1/4작은술 (손톱만큼)` · `60ml (15ml 통 4개)` · `약 250g (한 줌 쥐면 500원 동전 2개 반 굵기)` · `약 2~3큰술 (큐브 8개)`
- 어림을 단위로 바꾼 값은 「약」을 붙이고, 사용자에게 「제가 어림한 값」이라고 말해 확인받는다.
- 해 보니 모자랐다/남았다는 실제 경험은 재료 아래 작은 글씨로(예: 「3통도 됐지만 조금 모자랐어요」).
- 만드는 순서에도 양을 넣는다(예: 오일 3통으로 향 내고, 면 넣을 때 남은 1통).
- 큰술은 「T」 대신 「큰술」로. 원래 레시피 부분은 쿡매치에 적힌 표기 그대로 둔다.

## 쪽 나눔 (애매한 데서 잘리지 않게)

- 쪽은 `<div class="pg">` 로 **직접** 나눈다. `.pg` 는 `break-inside: avoid` + `break-after: page` — 한 쪽 안에서는 자르지 않는다.
- 쪽 크기 `@page 120mm 250mm`(폰 세로 비율). 내용이 넘치면 그 쪽이 통째로 다음 장으로 밀리거나 쪽 수가 늘어난다 → **PDF 쪽 수가 `.pg` 수와 같은지** 확인하고, 다르면 간격·글자를 줄이거나 덩어리를 다시 나눈다.
- 체크리스트 칸·순서 한 줄은 쪼개지지 않게(`break-inside: avoid`).

## 초록 상자 = 나만의 팁

쿡매치에서 찾은 원래 레시피를 **내 상황에 맞게 바꿔 쓴 2차 팁**(도구·장소·없던 재료·짐 줄이기). 「바꾼 것 + 왜」를 굵은 글씨 한 줄 + 설명으로.
- 중요한 이유부터, 사소한 대체(예: 참치액 → 코인육수)는 맨 아래. 원래와 똑같은 건(예: 치즈 그대로) 쓰지 않는다.
- 끝에 「집에서라면 원래 레시피대로 해도 된다」 같은 한 줄 메모.

## 노란 상자 (꼭 남긴다)

- 큰 글씨: **「앱스토어 · Play 스토어에서 ‘쿡매치’ 검색」**
- 굵게: 「‘<요리 검색어>’를 검색하면 이 레시피와 내 재료에 맞춘 대체 재료를 볼 수 있어요」
- 검은 버튼: **「👉 여기를 누르면 쿡매치 받기」** — 상자 전체가 링크.
- 링크: `https://refrigerator-code.vercel.app/download?utm_source=recipe_pdf_<요리이름>&utm_medium=pdf&utm_campaign=recipe_pdf`
  - `<요리이름>` 은 영문 소문자·밑줄, **요리 이름만**(캠핑 같은 상황은 넣지 않는다). 예: `recipe_pdf_shrimp_alioolio`.
  - 관리자 대시보드 「어디서 들어왔나」 표에 `recipe_pdf_…` 는 「레시피 PDF의 「쿡매치 받기」 링크 (요리이름)」으로 보인다(Admin.tsx `sourceLabel`). 새 레시피는 Admin.tsx 꼬리표 목록에 한 줄 추가.
- 따옴표는 Do Hyeon 글꼴에서 「」가 벌어져 보여서 ‘ ’ 를 쓴다.
- **로고(새 로고 P1 확정 2026-11-07)**: PDF 에는 원래부터 로고 이미지가 없고 노란 상자(#FFD600)+글자뿐이다. 새 로고의 바탕 노랑이 같은 값이라 **틀 변경 없음**(`scripts/make_dm_pdf.py` 확인). 이미 DM 으로 보낸 PDF 도 그대로. 나중에 로고를 넣고 싶으면 노란 상자 안에 `store/brand/wordmark_on_yellow.png`(투명, 검은 「쿡매치 CookMatch」)를 높이 40px 이하로 한 줄만 — 노란 상자 위에 마크를 놓을 때는 메인 아이콘(옅은 판 `store/brand/cookmatch_mark_1024.png` — 흰 타일이라 노랑 위에서 보임, 2026-11-08) 또는 더 진한 검정 바탕판(`store/brand/cookmatch_mark_reverse_1024.png`).
