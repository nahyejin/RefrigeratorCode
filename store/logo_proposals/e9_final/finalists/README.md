## 0. 왜 이 모양인가 — 「딱 맞는다」
네, 포인트는 **재료가 받침에 딱 맞게 앉는다 = 재료와 레시피가 맞는다(Cook + Match)** 이다. 그 포인트는 ① **간격**(재료와 받침 사이 얇은 틈, 항상 같은 폭) ② **앉는 깊이**(재료 중심이 받침 윗선) ③ **딱 하는 모션**(위에서 내려와 0.4초에 앉고 한 번 눌렸다 올라옴)으로 보인다. 하지 말 것: 둥둥 뜬 재료, 받침에 안 닿는 재료, 헐렁한 틈, 틈 없이 뭉친 모양, 너무 깊이 파묻힌 재료(`why_snug.png`).

## 3. 솔직한 순위와 트레이드오프
| | P12 (검정 바탕·앰버 받침) | P1 (노랑 바탕·흰 재료) | P14 (순백 바탕·노랑 재료) |
| --- | --- | --- | --- |
| 홈 화면 가시성 | 밝은·노랑 배경에서 강함, 어두운 배경에서 약함(받침·잎은 남음) | 밝은·어두운 배경에서 강함, **노랑 배경에서 사라짐** | 어두운·노랑 배경에서 강함, 밝은 배경에서 약함 |
| 브랜드 일관성(앱·스토어 노랑/검정) | ○ 검정 바탕 + 노랑 계열 | ○ 노랑 바탕 + 검정 받침(가장 직접적) | △ 흰 바탕(앱 UI 와는 어울리나 스토어의 노랑/검정과는 거리) |
| 카카오(노랑 바탕 + 검정 말풍선)와 구분 | ○ 가장 잘 구분됨 | △ 가장 닮음(노랑 타일 + 검정) | ○ 흰 바탕이라 구분됨 |
| 애플 연상 | 낮음~중간(흰 둥근 재료 + 두 잎, 한 입 먹은 모양 없음) | 낮음~중간(흰 둥근 재료) | 낮음(노랑 재료 + 두 잎이라 레몬/귤에 가깝다) |
| 위계(재료가 주인공) | ○ 재료↔바탕 17.3:1 > 받침 8.5:1 | △ 재료↔바탕 1.41(띠 2.7) < 받침 12.3 | △ 재료↔바탕 1.41(띠 3.9) < 받침 17.3 |
| 약점 | 어두운 배경화면에서 가장자리 | 노랑 배경·카카오와 닮음 | 흰 바탕이라 홈 화면에서 존재감 약함 |
**순위: 1 P12 → 2 P1 → 3 P14.** 이유: P12 만 주인공 위계가 숫자로 맞고(재료가 가장 강하다), 카카오와 가장 잘 구분되며, 앱·스토어의 노랑/검정과 일관된다. P1 은 브랜드 일관성은 최고지만 위계·카카오·노랑 배경 문제가 남는다. P14 는 깨끗하지만 위계와 존재감이 약하다.
**추천: P12(·a) 정식 + P1(·a) 노랑 반전(검정 장 위용) + P14(·c) 옅은 판** — 세 안이 한 가족으로 모두 쓰인다.

## 7. 솔직한 한계
- 대비비율은 계산값이지만 순위·「세련됨」·경쟁/애플 연상은 눈 판단이다. 상표 검색과 디자이너 검수가 필요하다.
