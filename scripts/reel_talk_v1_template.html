쿡매치 출연자 릴스 프롬프트

잘생기고 예쁜 출연자가 카메라를 보며 써 본 이야기를 하고, 중간중간 앱 기능 영상이 들어가는 형식이에요. 제미나이는 한 번에 8초 정도라서 출연자 부분을 클립 3개(A·B·C)로 나눠 뽑아요.

만드는 순서

  1. 출연자 사진을 먼저 만들어요(W·M 각각 한 번). 마음에 드는 얼굴이 나올 때까지 사진만 여러 번 뽑아도 돼요.
  2. 편마다 클립 A·B·C를 각각 새 대화에서, 그 출연자 사진을 첨부하고 프롬프트를 붙여 뽑아요. 사진을 붙여야 세 클립이 같은 사람·같은 옷·같은 장소로 나와요.
  3. 세 클립을 보내 주시면 편집할게요: A → 기능 영상 앞부분 → B → 기능 영상 뒷부분 → C → 쿡매치 로고·유도 화면 → 그 밖의 기능 7가지 → 끝 화면.

이렇게 짰어요

  • 사람이 한 명이라 지난번처럼 목소리가 꼬일 일이 없어요. 카메라를 보고 말하는 장면은 제미나이가 가장 안정적으로 만드는 구도예요.
  • 클립마다 대사는 한 문장(30자 안팎, 약 6초). 손에는 아무것도 들지 않고, 고개 끄덕임·미소·손짓 한두 번만.
  • 클립마다 목소리가 조금 달라질 수 있어요. 그러면 같은 사진으로 다시 뽑거나, 목소리만 편집에서 맞춰요.
  • 화면에 글자가 나오면 제외할 요소 칸에 자막, 글자, subtitles, captions, on-screen text
