# 쿠팡 파트너스 광고 설정 가이드

## 1. 쿠팡 파트너스 계정 생성

1. [쿠팡 파트너스](https://partners.coupang.com/) 접속
2. 회원가입 및 로그인
3. 광고 단위 생성

## 2. 광고 단위 ID 발급

1. 쿠팡 파트너스 대시보드 접속
2. "광고 단위 관리" 메뉴 선택
3. 새 광고 단위 생성
4. 광고 단위 ID 복사

## 3. 환경변수 설정

### 개발 환경 (`.env.development` 또는 `.env.local`)

```env
VITE_COUPANG_AD_UNIT_ID=your_coupang_ad_unit_id_here
```

### 프로덕션 환경

배포 플랫폼(Vercel, Railway 등)의 환경변수 설정에서:
- 키: `VITE_COUPANG_AD_UNIT_ID`
- 값: 쿠팡 파트너스에서 발급받은 광고 단위 ID

## 4. 광고 위치

현재 광고가 표시되는 위치:

1. **레시피 상세 페이지** (`RecipeDetail.tsx`)
   - 레시피 카드 아래
   - 레시피 정보 확인 후 자연스럽게 광고 노출

2. **레시피 리스트 페이지** (`RecipeList.tsx`)
   - 레시피 리스트와 페이지네이션 사이
   - 여러 레시피를 본 후 광고 노출

## 5. 광고 스타일 커스터마이징

`CoupangAd` 컴포넌트에 `style` prop을 전달하여 스타일을 변경할 수 있습니다:

```tsx
<CoupangAd 
  style={{ 
    marginTop: '32px',
    marginBottom: '32px',
    padding: '16px',
    backgroundColor: '#f5f5f5'
  }} 
/>
```

## 6. 개발 모드

개발 환경에서 광고 ID가 설정되지 않으면 회색 박스로 표시됩니다:
- "쿠팡 광고 영역" 텍스트
- 환경변수 설정 안내

## 7. 주의사항

1. **쿠팡 파트너스 정책 준수**
   - 광고 클릭 유도 금지
   - 허위/과장 광고 금지
   - 개인정보 수집 금지

2. **광고 위치**
   - 콘텐츠와 명확히 구분
   - 사용자 경험을 해치지 않는 위치

3. **모바일 최적화**
   - 모바일 화면에서도 잘 보이도록 설정
   - 반응형 디자인 고려

## 8. 수익 확인

쿠팡 파트너스 대시보드에서:
- 광고 노출 수
- 클릭 수
- 수익 확인 가능

## 9. 문제 해결

### 광고가 표시되지 않는 경우

1. 환경변수 확인
   - `VITE_COUPANG_AD_UNIT_ID`가 올바르게 설정되었는지 확인
   - 빌드 후에도 환경변수가 포함되었는지 확인

2. 쿠팡 파트너스 계정 확인
   - 광고 단위가 활성화되어 있는지 확인
   - 광고 단위 ID가 올바른지 확인

3. 브라우저 콘솔 확인
   - 스크립트 로드 오류 확인
   - 네트워크 오류 확인

## 10. 추가 광고 위치 제안

필요시 다음 위치에도 광고 추가 가능:

1. **인기 레시피 페이지** (`Popular.tsx`)
2. **마이페이지** (`MyPage.tsx`)
3. **레시피 리스트 중간** (예: 5개마다)
