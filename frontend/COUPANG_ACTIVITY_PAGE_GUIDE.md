## 1. 활동 페이지 등록 방법

### 1.1 접속 경로

1. **[쿠팡 파트너스 홈페이지](https://partners.coupang.com/)** 로그인
2. 우측 상단 **프로필 아이콘** 클릭
3. **"내 정보"** 또는 **"회원 정보"** 메뉴 선택
   - 또는 좌측 메뉴에서 **"내 정보"** 클릭

### 1.2 활동 페이지 등록 단계

#### Step 1: 활동 페이지 추가
1. **"활동 페이지"** 또는 **"활동 채널"** 섹션 찾기
2. **"활동 페이지 추가"** 또는 **"새 페이지 등록"** 버튼 클릭

#### Step 2: 페이지 정보 입력
다음 정보를 입력해야 합니다:

**필수 입력 항목:**
- **활동 페이지 URL**: 
  - 예: `https://refrigerator-code.vercel.app/recipe-list`
  - 예: `https://your-domain.com/popular`
  - ⚠️ **중요**: 파트너스 링크/배너가 있는 **모든 페이지**를 등록해야 합니다
  - ✅ **프로덕션 환경만 등록**: 실제 사용자가 접속하는 배포된 사이트만 등록하면 됩니다
  - ❌ **로컬 개발 환경은 등록 불필요**: `localhost:3000`, `localhost:5173` 등은 등록할 필요 없습니다
- **활동 페이지 유형**: 웹사이트, 모바일 앱, 블로그 등 선택
- **페이지 설명** (선택사항): 페이지에 대한 간단한 설명

**로컬 vs 배포 환경:**
- ✅ **등록 필요**: 배포된 프로덕션 사이트 (예: `https://your-domain.com`)
- ❌ **등록 불필요**: 로컬 개발 환경 (예: `http://localhost:3000`, `http://localhost:5173`)
- 💡 **이유**: 쿠팡 파트너스는 실제 사용자가 접속하는 공개된 페이지만 검토합니다

**등록해야 할 페이지 예시:**
- 냉장고 요리 페이지 (`/recipe-list`)
- 요즘 인기 페이지 (`/popular`)
- 내 냉장고 페이지 (`/my-fridge`)
- 마이 페이지 (`/my-page`)
- 기타 파트너스 링크가 있는 모든 페이지

#### Step 3: 저장
- **"저장"** 또는 **"등록"** 버튼 클릭
- 등록된 페이지 목록에 표시되는지 확인

### 1.3 활동 페이지 수정/삭제

- 등록된 페이지 옆에 **"수정"** 또는 **"삭제"** 버튼이 있습니다
- 언제든지 수정 및 추가가 가능합니다

## 2. 활동 스크린샷 등록 방법

### 2.1 스크린샷 준비

**촬영해야 할 내용:**
1. ✅ **파트너스 링크/배너**가 보이는 화면
2. ✅ **경제적 이해관계 표시** 문구가 함께 보이는 화면
   - "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

**스크린샷 촬영 방법:**
1. 앱/웹사이트에서 파트너스 광고가 표시되는 페이지로 이동
2. 광고와 경제적 이해관계 표시가 함께 보이도록 화면 캡처
3. 이미지 파일로 저장 (JPG, PNG 형식)

**스크린샷 예시:**
```
┌─────────────────────────────────────┐
│  레시피 카드                          │
│  [레시피 이미지]                      │
│  레시피 제목                          │
│                                      │
│  ┌───────────────────────────────┐  │
│  │ [설탕 쿠팡에서 구매하기] 버튼  │  │
│  └───────────────────────────────┘  │
│  이 게시물은 쿠팡 파트너스 활동의     │
│  일환으로, 이에 따른 일정액의        │
│  수수료를 제공받습니다.              │
└─────────────────────────────────────┘
```

### 2.2 스크린샷 등록

1. **"내 정보"** 페이지에서 등록한 활동 페이지 목록 확인
2. 등록한 페이지 옆에 **"스크린샷"** 또는 **"이미지 업로드"** 버튼 클릭
3. 준비한 스크린샷 이미지 파일 선택 및 업로드
4. 업로드 완료 후 확인

**주의사항:**
- 각 활동 페이지마다 스크린샷을 등록해야 합니다
- 스크린샷에는 반드시 파트너스 링크와 경제적 이해관계 표시가 함께 보여야 합니다

## 3. 최종 승인 상태 확인

### 3.1 최종 승인 상태 확인 방법

#### 방법 1: 대시보드 메인 페이지
1. 쿠팡 파트너스 대시보드 로그인
2. 메인 페이지 상단에 **최종 승인 상태** 표시 확인
   - ✅ **"최종 승인 완료"**: 승인 완료 상태
   - ⏳ **"최종 승인 대기"**: 승인 대기 중
   - ❌ **"최종 승인 반려"**: 반려된 상태 (재신청 필요)

#### 방법 2: 내 정보 페이지
1. 우측 상단 프로필 → **"내 정보"** 클릭
2. **"최종 승인"** 또는 **"승인 상태"** 섹션 확인

#### 방법 3: 이메일 확인
- 최종 승인 결과는 가입 시 등록한 이메일로 발송됩니다
- 이메일 제목: "쿠팡 파트너스 최종 승인 결과 안내"

### 3.2 최종 승인 조건

**자동 검토 조건:**
- 누적 판매금액이 **15만 원 이상** 시 자동으로 최종승인 채널 검토 진행

**최종 승인 전에도 가능한 것:**
- ✅ 실적 집계는 가능합니다
- ✅ 수익금은 발생합니다
- ❌ 하지만 **수익금 지급은 최종 승인 완료 후**에만 가능합니다

### 3.3 최종 승인 반려 사유 확인

반려된 경우:
1. 대시보드 상단에 **반려 사유 안내** 표시
2. 등록한 이메일로 **반려 사유 상세 안내** 메일 발송
3. **"내 정보"** 페이지에서 반려 사유 확인 가능

**가장 흔한 반려 사유:**
1. ❌ **경제적 이해관계 미표시**
   - 해결: 모든 파트너스 링크/배너가 있는 페이지에 경제적 이해관계 문구 표시
2. ❌ **활동 페이지 미등록**
   - 해결: 모든 활동 페이지를 등록하고 스크린샷 업로드

## 4. 최종 승인 재신청 방법

### 4.1 재신청 절차

#### Step 1: 반려 사유 확인 및 수정
1. 대시보드 또는 이메일에서 반려 사유 확인
2. 반려 사유에 해당하는 부분 수정:
   - 경제적 이해관계 표시 추가
   - 활동 페이지 등록 및 스크린샷 업로드

#### Step 2: 재신청
1. 쿠팡 파트너스 대시보드 접속
2. 대시보드 상단의 **"최종 승인 다시 신청하기"** 버튼 클릭
   - 또는 **"내 정보"** 페이지에서 재신청 버튼 클릭

#### Step 3: 재심사 대기
- 재신청 후 1-2일 내 재심사 진행
- 결과는 이메일 및 대시보드에서 확인 가능

### 4.2 재신청 시 체크리스트

재신청 전 반드시 확인:
- [ ] 모든 활동 페이지가 등록되어 있는가?
- [ ] 각 활동 페이지에 스크린샷이 등록되어 있는가?
- [ ] 모든 파트너스 링크/배너에 경제적 이해관계 표시가 있는가?
- [ ] 스크린샷에 파트너스 링크와 경제적 이해관계 표시가 함께 보이는가?

## 5. 현재 프로젝트 상태 확인

### 5.1 등록해야 할 페이지 URL (전체 목록)

**⚠️ 중요: 배포된 프로덕션 사이트의 URL만 등록하세요!**

현재 프로젝트에서 파트너스 링크/배너가 있는 모든 페이지:

#### 📌 필수 등록 페이지 (파트너스 링크가 있는 페이지)

1. **냉장고 요리 페이지** ⭐ (가장 중요)
   - URL: `https://your-domain.com/recipe-list`
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단에 부족한 재료 광고)
   - 설명: 레시피 카드 하단에 부족한 재료가 있을 때 광고 표시

2. **요즘 인기 페이지** ⭐
   - URL: `https://your-domain.com/popular`
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단) + `BottomCoupangAd` (페이지 하단)
   - 설명: 유튜브/네이버 인기 레시피 섹션에 광고 표시

3. **마이 페이지**
   - URL: `https://your-domain.com/my-page`
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단) + `BottomCoupangAd` (페이지 하단)
   - 설명: 내가 기록한 레시피, 완료한 레시피 섹션에 광고 표시

4. **내 냉장고 페이지**
   - URL: `https://your-domain.com/my-fridge`
   - 광고 유형: `BottomCoupangAd` (페이지 하단)
   - 설명: 페이지 하단에 광고 표시

5. **재료 상세 페이지**
   - URL: `https://your-domain.com/ingredient/:name` (예: `/ingredient/돼지고기`)
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단)
   - 설명: 해당 재료 관련 레시피 카드 하단에 광고 표시
   - ⚠️ **참고**: 동적 경로이므로 대표 URL 1개만 등록해도 됩니다 (예: `/ingredient/설탕`)

6. **레시피 상세 페이지**
   - URL: `https://your-domain.com/recipe-detail/:id` (예: `/recipe-detail/123`)
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단)
   - 설명: 레시피 상세 페이지의 관련 레시피 카드 하단에 광고 표시
   - ⚠️ **참고**: 동적 경로이므로 대표 URL 1개만 등록해도 됩니다 (예: `/recipe-detail/1`)

7. **내가 기록한 레시피 페이지**
   - URL: `https://your-domain.com/mypage/recorded`
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단)
   - 설명: 기록한 레시피 카드 하단에 광고 표시

8. **내가 완료한 레시피 페이지**
   - URL: `https://your-domain.com/mypage/completed`
   - 광고 유형: `CoupangProductAd` (레시피 카드 하단)
   - 설명: 완료한 레시피 카드 하단에 광고 표시

#### 📝 등록 예시 (배포 도메인이 `https://refrigerator-code.vercel.app`인 경우)

```
✅ 등록해야 할 URL:
1. https://refrigerator-code.vercel.app/recipe-list
2. https://refrigerator-code.vercel.app/popular
3. https://refrigerator-code.vercel.app/my-page
4. https://refrigerator-code.vercel.app/my-fridge
5. https://refrigerator-code.vercel.app/ingredient/설탕 (대표 URL)
6. https://refrigerator-code.vercel.app/recipe-detail/1 (대표 URL)
7. https://refrigerator-code.vercel.app/mypage/recorded
8. https://refrigerator-code.vercel.app/mypage/completed

❌ 등록 불필요 (로컬 개발 환경):
- http://localhost:5173/recipe-list
- http://localhost:3000/recipe-list
- http://127.0.0.1:5173/recipe-list
```

#### 💡 등록 팁

1. **동적 경로 처리**: 
   - `/ingredient/:name`, `/recipe-detail/:id` 같은 동적 경로는 대표 URL 1개만 등록해도 됩니다
   - 쿠팡 파트너스는 동일한 패턴의 페이지를 하나로 인식합니다

2. **우선순위**:
   - 가장 많이 사용되는 페이지부터 등록하세요
   - 필수: `/recipe-list`, `/popular` (가장 중요)
   - 선택: 나머지 페이지들

3. **스크린샷**:
   - 각 페이지마다 파트너스 링크와 경제적 이해관계 표시가 함께 보이는 스크린샷을 업로드하세요

### 5.2 스크린샷 촬영 가이드

**촬영할 화면:**
1. 레시피 카드가 표시되는 페이지
2. 레시피 카드 하단에 파트너스 광고가 보이는 화면
3. 광고 하단에 경제적 이해관계 표시 문구가 함께 보이는 화면

**촬영 팁:**
- 모바일 화면과 데스크톱 화면 모두 촬영 권장
- 여러 레시피 카드가 보이는 전체 화면 촬영
- 광고와 경제적 이해관계 표시가 명확히 보이도록 확대

## 6. 문제 해결

### 6.1 활동 페이지를 찾을 수 없는 경우

**확인 사항:**
1. 우측 상단 프로필 → "내 정보" 메뉴 확인
2. 좌측 메뉴에서 "내 정보" 또는 "회원 정보" 확인
3. 브라우저 캐시 삭제 후 재접속

### 6.2 스크린샷 업로드가 안 되는 경우

**확인 사항:**
1. 이미지 파일 형식 확인 (JPG, PNG 권장)
2. 파일 크기 확인 (일반적으로 5MB 이하)
3. 활동 페이지가 먼저 등록되어 있는지 확인

### 6.3 최종 승인 상태가 보이지 않는 경우

**가능한 원인:**
1. 아직 누적 판매금액이 15만 원 미만일 수 있음
2. 최종 승인 검토가 아직 시작되지 않았을 수 있음
3. 계정이 최근에 생성되어 승인 프로세스가 진행 중일 수 있음

**해결 방법:**
- 쿠팡 파트너스 고객센터로 문의: `partners@coupang.com`
- 또는 대시보드의 "문의하기" 기능 사용
