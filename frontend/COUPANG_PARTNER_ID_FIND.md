# 쿠팡 파트너스 파트너 ID 찾기

## 파트너 ID 확인 방법

### 방법 1: 간편 링크 만들기 페이지에서 확인 (가장 쉬운 방법)

1. [쿠팡 파트너스 대시보드](https://partners.coupang.com/) 로그인
2. 좌측 메뉴에서 **"간편 링크 만들기"** 클릭
3. 페이지 상단 또는 URL에 파트너 ID 표시
   - URL 예시: `https://partners.coupang.com/link/create?partnerId=12345678`
   - 여기서 `12345678`이 파트너 ID입니다

### 방법 2: 대시보드 메인 페이지

1. 쿠팡 파트너스 대시보드 로그인
2. 메인 페이지에서 우측 상단 또는 좌측 메뉴 확인
3. "파트너 ID" 또는 "Partner ID" 표시 확인

### 방법 3: 프로필 메뉴

1. 우측 상단 **프로필 아이콘** 클릭
2. 드롭다운 메뉴에서 **"파트너 ID"** 또는 **"Partner ID"** 확인
   - ⚠️ "ID: AF2929738" 같은 것은 계정 ID이므로 파트너 ID가 아닙니다
   - 파트너 ID는 별도로 표시되어 있습니다

### 방법 4: 광고 단위 관리 페이지

1. 좌측 메뉴에서 **"광고 단위 관리"** 클릭
2. 페이지 상단 또는 URL에 파트너 ID 표시

## 파트너 ID 형식

- ✅ **올바른 형식**: `12345678` (8자리 숫자만)
- ❌ **잘못된 형식**: `AF2929738` (알파벳 포함, 계정 ID)

## 파트너 ID가 보이지 않는 경우

1. **최종 승인 전**: 최종 승인이 완료되지 않았을 수 있습니다
2. **페이지 위치**: 다른 메뉴에서 확인해보세요
3. **브라우저 캐시**: 브라우저 새로고침 또는 캐시 삭제

## 다음 단계

파트너 ID를 찾으셨다면:
1. `.env.local` 파일에 파트너 ID 설정
2. 개발 서버 재시작
3. 테스트
