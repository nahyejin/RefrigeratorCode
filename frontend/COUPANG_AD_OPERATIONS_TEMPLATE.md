# 쿠팡 광고 운영 템플릿 (재료 기반)

이 문서는 `냉장고 요리/요즘 인기` 카드 하단에 노출하는 쿠팡 광고를
`재료(keyword)` 기준으로 운영하기 위한 실무 템플릿입니다.

현재 코드 구조상 핵심은 아래 1줄입니다.

- 부족 재료명 -> 기준 `keyword`로 정규화 -> CSV의 `coupang_link` 조회 -> 광고 링크 노출

---

## 1) 현재 데이터 파일(원본)

- 파일: `frontend/public/ingredient_profile_dict_with_substitutes.csv`
- 주요 컬럼:
  - `keyword` (기준 재료명)
  - `대분류` (재료 여부 판단용, `재료`만 광고 대상)
  - `synonyms` (동의어)
  - `coupang_link` (쿠팡 파트너스 링크)

운영 원칙:

- `keyword`는 절대 중복 없이 1개만 유지
- 광고 링크는 반드시 `keyword` 행의 `coupang_link`에만 입력
- 동의어 행에는 광고 링크를 넣지 않음 (동의어는 `synonyms`로 매핑)

---

## 2) 엑셀 운영 시트 권장 구조

아래 컬럼으로 "운영용 엑셀"을 만들고, 최종 반영 시 CSV에 동기화합니다.

| 컬럼명 | 설명 | 예시 |
|---|---|---|
| keyword | 기준 재료명(필수) | 고추 |
| category | `대분류` 값, 광고 대상은 `재료` | 재료 |
| synonyms | 동의어(쉼표 구분) | 청양고추,풋고추 |
| coupang_link | 파트너스 링크(필수) | https://link.coupang.com/... |
| ad_status | 운영 상태 | active / hold / draft |
| priority | 입력 우선순위 | P0 / P1 / P2 |
| owner | 입력 담당자 | 홍길동 |
| updated_at | 마지막 수정일 | 2026-04-14 |
| memo | 비고(상품 변경 이유 등) | CTR 낮아 교체 |

실제 서비스 반영 컬럼은 `keyword`, `synonyms`, `coupang_link`만 있으면 동작합니다.

---

## 3) 우선순위 선정 방법 (처음 1~2주)

모든 재료를 한 번에 채우지 말고, 아래 순서로 채웁니다.

1. **P0 (최우선)**: 자주 부족한 재료 Top 50~100
2. **P1**: 냉장고 기본 재료 + 카드 노출 빈도 높은 재료
3. **P2**: 나머지 롱테일 재료

권장 목표:

- 1차 오픈: P0만 채워도 체감 광고 커버리지 확보
- 2차: P1 확장
- 3차: P2 보완 + 저성과 링크 교체

---

## 4) 입력 규칙 (중요)

1. **링크 규칙**
   - 쿠팡 파트너스에서 발급받은 링크만 사용
   - 리다이렉트/단축 링크 임의 가공 금지

2. **재료명 규칙**
   - `keyword`는 표준명으로 통일 (예: 고추)
   - 유사 표현은 `synonyms`에 추가 (예: 청양고추, 풋고추)

3. **카테고리 규칙**
   - `대분류=재료`인 행만 광고 링크 입력
   - `TPO`, `효능`, `대상` 같은 비재료 키워드에는 링크 미입력

4. **빈 링크 처리**
   - `coupang_link`가 비어 있으면 코드가 fallback 검색 링크를 사용
   - 운영상 비권장 재료는 `ad_status=hold`로 명시

---

## 5) 일일/주간 운영 루틴

- 일일(또는 격일)
  - 신규 부족재료 상위 키워드 확인
  - `coupang_link` 비어 있는 키워드 채우기

- 주간
  - 클릭률(CTR) 낮은 키워드 교체
  - 품절/죽은 링크 점검
  - 문구/노출 정책 준수 재확인

---

## 6) 정책 준수 체크리스트

- [ ] 광고/제휴 문구가 카드 하단에 노출된다
- [ ] 파트너스 링크가 등록된 활동 페이지에서만 노출된다
- [ ] 과장/오해 유도 문구를 사용하지 않는다
- [ ] 클릭 강제 UX(팝업 강제, 오버레이 유도)를 사용하지 않는다

---

---

## 8) 실제 반영 절차 (비개발자 협업용)

1. 운영 엑셀에서 `coupang_link` 업데이트
2. 개발자가 `ingredient_profile_dict_with_substitutes.csv`에 반영
3. 스테이징/로컬에서 재료별 링크 클릭 확인
4. 배포 후 쿠팡 파트너스 활동 페이지/스크린샷 상태 점검

이 흐름으로 가면 "재료가 많아서 막막한 문제"를 운영 표준으로 해결할 수 있습니다.
