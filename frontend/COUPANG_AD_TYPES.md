# 쿠팡 파트너스 광고 타입별 설명

## 1. 간편 링크 (Simple Link)

### 특징
- ✅ **웹/앱 모두 사용 가능**: 일반 URL 링크이므로 어디서나 사용 가능
- ✅ **검색 결과 페이지 연결**: 특정 키워드 검색 결과로 연결
- ✅ **간단한 구현**: `<a>` 태그로 바로 사용 가능

### 사용 방법
1. 쿠팡 파트너스 대시보드 → "간편 링크 만들기"
2. 검색 URL 입력: `https://www.coupang.com/np/search?q=돼지고기`
3. 생성된 간편 링크 복사: `https://link.coupang.com/a/AF2929738?linkCode=...`
4. 앱/웹에서 `<a>` 태그로 사용

### 현재 구현 상태
- `CoupangProductAd` 컴포넌트에서 사용 중
- 재료명을 기반으로 검색 URL 생성
- ⚠️ **주의**: 현재는 검색 URL을 직접 사용 중 (간편 링크로 변환 권장)

### 앱에서 사용 가능 여부
✅ **가능합니다!** 일반 URL 링크이므로:
- React Native: `<TouchableOpacity>` + `Linking.openURL()`
- 웹 앱: `<a>` 태그
- 모바일 웹: `<a>` 태그 (현재 사용 중)

---

## 2. 다이내믹 배너 (Dynamic Banner)

### 특징
- ❌ **웹 전용**: JavaScript가 지원되는 웹페이지에서만 사용 가능
- ✅ **자동 상품 추천**: 사용자 관심사 기반으로 상품 자동 추천
- ✅ **높은 클릭율**: 일반 배너보다 클릭율이 높음
- ❌ **앱에서 사용 불가**: JavaScript 스크립트 필요

### 사용 방법
1. 쿠팡 파트너스 대시보드 → "다이내믹 배너"
2. 배너 타입과 카테고리 선택
3. 생성된 JavaScript 스크립트 복사
4. 웹페이지에 스크립트 삽입

### 앱에서 사용 가능 여부
❌ **불가능합니다!** 
- JavaScript 스크립트 필요
- React Native 앱에서는 사용 불가
- 웹뷰를 사용하는 경우에만 가능 (제한적)

---

## 3. 현재 프로젝트에 적합한 방식

### 추천: 간편 링크 사용 (현재 방식)

**이유**:
1. ✅ 웹/앱 모두 호환
2. ✅ 구현이 간단
3. ✅ 재료명 기반 검색에 적합
4. ✅ 모바일 웹에서 잘 작동

**개선 사항**:
- 현재는 검색 URL을 직접 사용 중
- 간편 링크로 변환하면 수익 추적이 더 정확함

---

## 4. 간편 링크 vs 다이내믹 배너 비교

| 항목 | 간편 링크 | 다이내믹 배너 |
|------|----------|--------------|
| 웹 사용 | ✅ 가능 | ✅ 가능 |
| 앱 사용 | ✅ 가능 | ❌ 불가능 |
| 구현 난이도 | ⭐ 쉬움 | ⭐⭐ 보통 |
| 수익 추적 | ✅ 정확 | ✅ 정확 |
| 자동 추천 | ❌ 없음 | ✅ 있음 |
| 클릭율 | 보통 | 높음 |

---

## 5. 현재 프로젝트 권장 사항

### 현재 상황
- `CoupangProductAd` 컴포넌트 사용 중
- 재료명 기반 검색 링크 생성
- 모바일 웹 환경

### 권장 사항
1. **간편 링크 계속 사용** ✅
   - 현재 방식이 앱/웹 모두에 적합
   - 구현이 간단하고 안정적

2. **간편 링크로 변환** (선택사항)
   - 주요 재료에 대해 간편 링크 미리 생성
   - 수익 추적 정확도 향상

3. **다이내믹 배너는 사용하지 않음** ❌
   - 웹 전용이므로 현재 프로젝트에 부적합
   - JavaScript 스크립트 필요
