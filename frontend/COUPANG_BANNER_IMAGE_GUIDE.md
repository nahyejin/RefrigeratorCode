# 쿠팡 파트너스 배너 이미지 가이드

## 문제 상황

현재 `CoupangProductAd` 컴포넌트는 **간편 링크(Simple Link)**를 사용하고 있습니다. 간편 링크는 단순 URL이므로 **자동으로 상품 이미지나 배너를 제공하지 않습니다**.

## 해결 방법

### 방법 1: 간편 링크 + 수동 이미지 추가 (현재 방식 개선)

간편 링크를 사용하면서 상품 이미지를 수동으로 추가할 수 있습니다:

1. **CSV에 이미지 URL 추가**
   - `ingredient_profile_dict_with_substitutes.csv`에 `coupang_image_url` 컬럼 추가
   - 각 재료별로 쿠팡 상품 이미지 URL 저장

2. **컴포넌트에서 이미지 표시**
   - `CoupangProductAd` 컴포넌트에서 이미지 URL 로드
   - 링크 위에 상품 이미지 표시

**장점**: 간편 링크 유지, 구현 간단
**단점**: 이미지 URL을 수동으로 관리해야 함

### 방법 2: 쿠팡 파트너스 다이나믹 배너 사용

쿠팡 파트너스에서 제공하는 **다이나믹 배너**를 사용하면 자동으로 상품 이미지가 표시됩니다.

1. **쿠팡 파트너스 대시보드에서 다이나믹 배너 생성**
   - 대시보드 → "다이나믹 배너" 메뉴
   - 배너 타입 선택 (상품 배너, 카테고리 배너 등)
   - 생성된 JavaScript 코드 복사

2. **컴포넌트에 스크립트 삽입**
   - 쿠팡에서 제공한 JavaScript 코드를 컴포넌트에 삽입
   - 상품 정보가 자동으로 표시됨

**장점**: 자동으로 상품 정보 및 이미지 표시
**단점**: JavaScript 스크립트 필요, 웹 전용

### 방법 3: 쿠팡 파트너스 API 사용 (고급)

쿠팡 파트너스 API를 사용하여 상품 정보를 가져올 수 있습니다:

1. **API 키 발급**
   - 쿠팡 파트너스 대시보드 → API 설정
   - API 키 발급

2. **상품 정보 조회**
   - 상품 ID 또는 검색 키워드로 상품 정보 조회
   - 상품 이미지, 가격, 리뷰 등 정보 가져오기

3. **컴포넌트에 표시**
   - 가져온 정보를 컴포넌트에 표시

**장점**: 완전한 제어 가능, 상품 정보 자동 업데이트
**단점**: API 키 관리 필요, 구현 복잡

## 현재 프로젝트 권장 사항

### 추천: 방법 1 (간편 링크 + 수동 이미지)

**이유**:
1. 현재 간편 링크 방식 유지 가능
2. 구현이 간단함
3. 웹/앱 모두 호환
4. 이미지 URL을 CSV에 저장하여 관리 용이

**구현 방법**:
1. CSV에 `coupang_image_url` 컬럼 추가
2. 각 재료별로 쿠팡 상품 이미지 URL 저장
3. `CoupangProductAd` 컴포넌트에서 이미지 표시

### 대안: 방법 2 (다이나믹 배너)

웹 전용으로 사용 가능하지만, JavaScript 스크립트가 필요하므로 현재 프로젝트 구조에 맞게 수정이 필요합니다.

## 참고

- **간편 링크**: 단순 URL, 이미지 자동 제공 안됨
- **다이나믹 배너**: JavaScript 스크립트, 자동 이미지 제공
- **API**: 완전한 제어 가능, 구현 복잡
