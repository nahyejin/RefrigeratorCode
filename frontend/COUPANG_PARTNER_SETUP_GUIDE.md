## 1. 쿠팡 파트너스 계정 생성

### 1.1 회원가입
1. [쿠팡 파트너스](https://partners.coupang.com/) 접속
2. "회원가입" 클릭
3. 개인정보 입력 및 약관 동의
4. 이메일 인증 완료

### 1.2 계정 승인 대기
- 가입 후 1-2일 내 승인 완료
- 승인 완료 시 이메일 알림

## 2. 파트너 ID 발급

### 2.1 파트너 ID 확인
1. 쿠팡 파트너스 대시보드 로그인
2. 우측 상단 프로필 클릭
3. **"파트너 ID"** 확인 및 복사
   - 형식: `12345678` (8자리 숫자)

### 2.2 광고 단위 ID (선택사항)
- 일반 배너 광고를 사용하는 경우에만 필요
- 대시보드 > "광고 단위 관리" > 새 광고 단위 생성

## 3. 환경변수 설정

### 3.1 로컬 개발 환경

프로젝트 루트에 `.env.local` 파일 생성:

```env
# 쿠팡 파트너스 파트너 ID (필수)
VITE_COUPANG_PARTNER_ID=12345678

# 쿠팡 광고 단위 ID (선택사항 - 배너 광고 사용 시)
VITE_COUPANG_AD_UNIT_ID=your_ad_unit_id_here
```

⚠️ **주의**: `.env.local` 파일은 `.gitignore`에 포함되어 있어야 합니다.

### 3.2 프로덕션 환경 (Vercel)

1. Vercel 대시보드 접속
2. 프로젝트 선택 > Settings > Environment Variables
3. 다음 환경변수 추가:

| Key | Value | Environment |
|-----|-------|-------------|
| `VITE_COUPANG_PARTNER_ID` | `12345678` (본인의 파트너 ID) | Production, Preview, Development |
| `VITE_COUPANG_AD_UNIT_ID` | `your_ad_unit_id` (선택사항) | Production, Preview, Development |

4. 저장 후 재배포

### 3.3 프로덕션 환경 (Railway)

1. Railway 대시보드 접속
2. 프로젝트 선택 > Variables 탭
3. 환경변수 추가 후 재배포

## 4. 간편 링크 생성

### 4.1 왜 간편 링크가 필요한가?

`CoupangProductAd` 컴포넌트는 재료명을 기반으로 쿠팡 검색 링크를 생성합니다. 하지만 **파트너스 수익을 받으려면 간편 링크로 변환**해야 합니다.

### 4.2 간편 링크 생성 방법

#### 방법 1: 쿠팡 파트너스 대시보드에서 생성

1. 쿠팡 파트너스 대시보드 접속
2. "간편 링크 생성" 메뉴 선택
3. 검색 URL 입력:
   ```
   https://www.coupang.com/np/search?q=돼지고기
   ```
4. "간편 링크 생성" 클릭
5. 생성된 링크 복사:
   ```
   https://link.coupang.com/a/12345678?linkCode=as2&tag=your_tag&itemId=1234567890
   ```

#### 방법 2: API를 통한 자동 변환 (고급)

현재 `CoupangProductAd` 컴포넌트는 검색 URL을 직접 생성합니다. 간편 링크를 자동으로 생성하려면:

1. 쿠팡 파트너스 API 사용 (공식 API 제공 시)
2. 또는 백엔드에서 간편 링크 변환 서비스 구현

### 4.3 간편 링크 매핑 테이블 생성 (권장)

자주 사용하는 재료에 대해 간편 링크를 미리 생성하여 매핑:

```typescript
// frontend/src/utils/coupangLinks.ts
export const COUPANG_INGREDIENT_LINKS: { [key: string]: string } = {
  '돼지고기': 'https://link.coupang.com/a/12345678?linkCode=as2&tag=...',
  '소고기': 'https://link.coupang.com/a/12345678?linkCode=as2&tag=...',
  '닭고기': 'https://link.coupang.com/a/12345678?linkCode=as2&tag=...',
  // ... 더 많은 재료
};
```

## 5. 광고 타입별 설정

### 5.1 재료 기반 상품 링크 (`CoupangProductAd`)

**현재 사용 위치**: `RecipeCard.tsx`
- 부족한 재료가 정확히 1개일 때 표시
- 재료명을 기반으로 쿠팡 검색 링크 생성

**설정 필요 사항**:
- ✅ `VITE_COUPANG_PARTNER_ID` 환경변수 설정
- ⚠️ 간편 링크로 변환 권장 (수익 추적을 위해)

### 5.2 일반 배너 광고 (`CoupangAd`)

**사용 위치**: 원하는 위치에 추가

```tsx
import CoupangAd from '../components/CoupangAd';

<CoupangAd />
```

**설정 필요 사항**:
- ✅ `VITE_COUPANG_AD_UNIT_ID` 환경변수 설정

### 5.3 하단 광고 (`BottomCoupangAd`)

**사용 위치**: 페이지 하단

```tsx
import BottomCoupangAd from '../components/BottomCoupangAd';

<BottomCoupangAd 
  showCondition={!loading && total > 0}
/>
```

**설정 필요 사항**:
- ✅ `VITE_COUPANG_AD_UNIT_ID` 환경변수 설정

## 6. 테스트 및 확인

### 6.1 개발 환경에서 테스트

1. `.env.local` 파일에 파트너 ID 설정
2. 개발 서버 재시작:
   ```bash
   npm run dev
   ```
3. 브라우저에서 확인:
   - 개발 모드에서는 회색 박스로 표시됨
   - 환경변수가 설정되면 실제 광고 표시

### 6.2 프로덕션 환경에서 확인

1. 환경변수 설정 후 재배포
2. 실제 사이트에서 광고 표시 확인
3. 쿠팡 파트너스 대시보드에서 노출 수 확인

### 6.3 수익 추적

1. 쿠팡 파트너스 대시보드 접속
2. "수익 현황" 메뉴에서 확인:
   - 광고 노출 수
   - 클릭 수
   - 수익 금액

## 7. 문제 해결

### 7.1 광고가 표시되지 않는 경우

**확인 사항**:
1. ✅ 환경변수가 올바르게 설정되었는지
2. ✅ 빌드 후에도 환경변수가 포함되었는지 (Vite는 빌드 시점에 환경변수 포함)
3. ✅ 브라우저 콘솔에 오류가 없는지
4. ✅ 쿠팡 파트너스 계정이 활성화되어 있는지

**해결 방법**:
```bash
# 환경변수 확인
echo $VITE_COUPANG_PARTNER_ID

# 재빌드
npm run build
```

### 7.2 간편 링크가 작동하지 않는 경우

- 간편 링크는 쿠팡 파트너스 대시보드에서 생성한 링크를 사용해야 함
- 직접 생성한 검색 URL은 파트너스 수익이 발생하지 않을 수 있음

### 7.3 수익이 발생하지 않는 경우

1. **간편 링크 사용 확인**: 검색 URL이 아닌 간편 링크 사용
2. **쿠키 설정 확인**: 사용자가 쿠팡 쿠키를 허용해야 함
3. **구매 완료 확인**: 클릭만으로는 수익이 발생하지 않으며, 실제 구매가 완료되어야 함

## 8. 쿠팡 파트너스 정책 준수

### 8.1 필수 준수 사항

- ❌ **광고 클릭 유도 금지**: "클릭하세요", "구매하세요" 등의 문구 사용 금지
- ❌ **허위/과장 광고 금지**: 실제와 다른 정보 제공 금지
- ❌ **개인정보 수집 금지**: 광고를 통한 개인정보 수집 금지
- ✅ **광고 표시 명시**: "이 게시물은 쿠팡 파트너스 활동의 일환으로..." 문구 포함 (이미 구현됨)

### 8.2 권장 사항

- 광고 위치는 콘텐츠와 명확히 구분
- 사용자 경험을 해치지 않는 위치에 배치
- 모바일 화면에서도 잘 보이도록 반응형 디자인 적용

## 9. 다음 단계

### 9.1 간편 링크 자동화

현재는 수동으로 간편 링크를 생성해야 합니다. 향후 개선 방안:

1. **백엔드 API 구현**: 재료명을 받아 간편 링크 반환
2. **캐싱**: 자주 사용하는 재료의 간편 링크를 캐싱
3. **동적 생성**: 쿠팡 파트너스 API를 통한 자동 간편 링크 생성

### 9.2 추가 광고 위치

필요시 다음 위치에도 광고 추가 가능:

- 레시피 리스트 중간 (예: 5개마다)
- 레시피 상세 페이지
- 인기 레시피 페이지
