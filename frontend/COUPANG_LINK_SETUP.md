# 쿠팡 파트너스 링크 설정 가이드

## 개요

재료별로 쿠팡 파트너스 상품 링크를 직접 연결하여 더 정확한 수익 추적을 할 수 있습니다.

## CSV 파일 수정 방법

### 1. `ingredient_profile_dict_with_substitutes.csv` 파일 열기

### 2. 헤더에 `coupang_link` 컬럼 추가

현재 헤더:
```csv
keyword,대분류,중분류,소분류,세분류,세세분류,Feature,synonyms,hyperonym,타사전추가여부,
```

수정 후 헤더:
```csv
keyword,대분류,중분류,소분류,세분류,세세분류,Feature,synonyms,hyperonym,타사전추가여부,coupang_link,
```

### 3. 각 재료 행에 쿠팡 파트너스 링크 추가

#### 쿠팡 파트너스 링크 생성 방법

1. **쿠팡 파트너스 대시보드 접속**
   - [쿠팡 파트너스 대시보드](https://partners.coupang.com/) 로그인

2. **간편 링크 만들기**
   - 좌측 메뉴 → **"간편 링크 만들기"** 클릭
   - 상품 URL 또는 검색 URL 입력
   - **"간편 링크 생성"** 클릭

3. **생성된 링크 복사**
   - 예시: `https://link.coupang.com/a/AF2929738?linkCode=as2&tag=...&itemId=1234567890`
   - 또는: `https://link.coupang.com/a/AF2929738?linkCode=as2&tag=...&url=검색URL`

#### CSV에 링크 추가 예시

**설탕** 예시:
```csv
설탕,재료,양념/조미료,단맛 조미,설탕류,,"단맛, 하얀색, 필수조미료, 가루류, 입자감, 조리보조","흑설탕, 각설탕, 유기농설탕, 갈색설탕, 황설탕, 백설탕",,,https://link.coupang.com/a/AF2929738?linkCode=as2&tag=...&itemId=1234567890,
```

**돼지고기** 예시:
```csv
돼지고기,재료,식재료 원물,육류/수산/달걀,육류,돼지고기류,"다용도, 대중육, 고기향, 단백질, 필수베이스, 가열용, 기름짐",돈육,,,https://link.coupang.com/a/AF2929738?linkCode=as2&tag=...&itemId=9876543210,
```

### 4. 링크가 없는 경우

- 링크가 없는 재료는 **빈 값**으로 두면 됩니다
- 빈 값인 경우 자동으로 검색 결과 페이지로 연결됩니다 (fallback)

## 주의사항

1. **UTF-8-BOM 인코딩**: Excel에서 저장 시 UTF-8-BOM 형식으로 저장해야 합니다
2. **링크 형식**: 쿠팡 파트너스 대시보드에서 생성한 간편 링크를 사용하세요
3. **파트너 ID 확인**: 링크에 파트너 ID(`AF2929738`)가 포함되어 있는지 확인하세요
4. **상품 선택**: 각 재료에 가장 적합한 대표 상품을 선택하세요

## 작업 순서

1. 자주 사용되는 재료부터 시작 (예: 설탕, 돼지고기, 소고기, 닭고기 등)
2. 쿠팡 파트너스 대시보드에서 각 재료별로 간편 링크 생성
3. CSV 파일에 링크 추가
4. 테스트: 레시피 카드에서 링크가 올바르게 작동하는지 확인

## 자동화 (선택사항)

모든 재료에 대해 일괄로 링크를 추가하는 것은 시간이 많이 걸릴 수 있습니다.
따라서:
- **우선순위**: 자주 사용되는 재료부터 링크 추가
- **점진적 추가**: 필요에 따라 재료별로 링크 추가
- **Fallback**: 링크가 없는 재료는 자동으로 검색 결과 페이지로 연결
